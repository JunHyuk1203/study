# study UI

설치나 빌드가 필요 없는 HTML/CSS/JavaScript 화면입니다. 탭 슬라이드까지 보려면 이 폴더에서 `python -m http.server 5173 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:5173/`을 여세요. 파일을 직접 열면 화면은 표시되지만 탭 이동은 일반 페이지 이동으로 처리됩니다.

- 홈: `index.html`
- 학습: `study.html`
- AI: `ai.html`
- 학교: `school.html` (하단 학교 탭)
- 플레이: `play.html`
- 계정: `account.html`
- 공통 스타일: `styles.css`

UI.pdf의 화면 배치를 바탕으로 구성했습니다. 브랜드명, 색상, 문구와 데이터는 UI 확인을 위한 예시입니다. 화면 이동 링크, 메뉴 순서에 따른 좌우 전환 애니메이션과 상단바 스크롤 숨김만 연결했으며 AI, 타이머, 카메라, 학교 연동, 로그인, 결제 및 데이터 저장은 구현하지 않았습니다. 외부 라이브러리와 외부 서비스 요청은 사용하지 않으며, 탭 이동 시 같은 서버의 HTML 파일만 가져옵니다.

검증: 6개 화면 브라우저 렌더링 확인, 내부 파일 링크 및 스타일 파일 존재 확인, 하단 학교 탭, 홈의 AI 진입 링크 및 상단바 스크롤 동작 확인.
