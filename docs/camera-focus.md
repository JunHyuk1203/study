# 카메라 집중 감지

학습 탭에서 기존 스터디캠을 시작하면 모델 준비 후 자동 분석한다. 별도 피드백, 판정 확인, 사용자별 수동 보정은 없다. 최초 브라우저 카메라 접근 권한은 필요하다. 기존 수동 일시정지 버튼은 사용자가 원할 때 사용할 수 있으며 자동 판정이 이를 해제하지 않는다.

## 자동 판정

| 행동 | 신호 | 경고 기준 |
| --- | --- | --- |
| 수면·졸음 | 양쪽 눈의 눈꺼풀 비율 또는 양쪽 eyeBlink 점수 | 1.5초 연속 눈 감음 |
| 휴대폰 사용 | COCO-SSD 휴대폰 + 손/손목 근접 + 아래를 보거나 얼굴 가까이에 든 자세 | 1.5초 지속 |
| 자리 이탈 | 얼굴과 상체 어깨가 모두 사라짐 | 2초 지속 |
| 멍때림 추정 | 머리·홍채·양쪽 손목 움직임이 매우 적고 독서/책 접촉/노트북을 보는 단서가 없음 | 45초 지속 |

휴대폰·이탈 의심이 처음 관측되는 즉시 시간 적립을 멈추고, 기준 시간 이후 빨간 경고를 표시한다. 눈 감음은 정상 깜빡임을 제외하기 위해 350ms까지 기존 측정을 유지하고, 그 이상이면 적립을 멈추며 1.5초 이후 경고한다. 정상 깜빡임마다 타이머를 정지·재개하지 않는다. 정상 행동이 2초 지속되면 경고 해제와 시간 측정을 자동 재개한다. 멍때림은 45초 관측 후 정지한다. 이 대기 시간을 소급해서 차감하지 않는다.

얼굴만 또는 상체만 보여 판정이 불확실할 때도 시간을 적립하지 않는다. 두 어깨와 얼굴이 보이는 구도로 설치한다. 양쪽 손목이 보이지 않으면 장시간 정지 판정을 생략하지만 다른 판정은 계속한다. 객체만 책상 위에 있는 휴대폰은 사용으로 판정하지 않는다. 화면 밖 휴대폰은 탐지할 수 없다.

## 실행 및 데이터

전체 화면 스터디캠의 안내 문구 아래에 개발 테스트용 ‘감지 타이머’를 표시한다. 네 행동의 현재 감지 지속 시간, 정지까지 남은 시간, 경고까지 남은 시간을 분석 프레임마다 갱신한다. 즉시 정지하는 휴대폰·자리 이탈은 ‘즉시 정지’로 표시한다. 멍때림은 움직임이 적게 유지된 최근 구간의 남은 시간을 보여주며, 학습 단서 또는 손목 미인식으로 판정이 억제되면 그 이유를 표시한다. 정상 행동 복귀 중에는 재개까지 남은 시간도 표시한다. 표시를 위한 계산은 판정 기준이나 서버 타이머를 변경하지 않으며 별도 업로드를 하지 않는다.

- MediaPipe Face/Pose/Hand를 각 프레임에, COCO-SSD를 최소 800ms 간격으로 실행한다. 중복 추론은 실행하지 않는다. 프레임은 작업 후 해제한다.
- 얼굴 랜드마크 전체 대신 아바타용 3개 점과 파생 행동 신호만 Worker에서 UI로 전달한다. 원본 영상·좌표·객체 기록을 저장하거나 업로드하지 않는다.
- 모델 초기화 중, 오류, 카메라 음소거/종료, 추론 응답 3초 초과, 오래된 결과, 화면 이탈 중에는 적립을 중단한다. 기존 SP word 동반 실행의 화면 이탈 예외는 유지한다.
- Worker 실패 시 같은 모델 전체를 호환 모드에서 실행한다. 얼굴 존재 여부만 확인하는 축소 모드로 시간을 적립하지 않는다. 호환 모드도 실패하면 오류를 표시하고 정지를 유지한다.
- 기존 `study:camera-changed` 이벤트와 `cameraState().tracking`으로 로컬 표시와 서버 타이머 동기화를 연결한다. 서버 통계/저장 API는 변경하지 않는다.

## 정확도와 검증

사전 학습 모델이 검출한 특징에 시간 규칙을 적용한다. 집중력·공부 이해도·수면 자체를 확정하는 전용 분류 모델은 아니다. 조명, 안경, 촬영 각도, 손/책 가림에 따라 오탐·미탐이 생기며, 조용한 독서와 멍때림을 완벽히 구별할 수 없다. 책을 내려다보거나 노트북을 보는 문맥은 오탐을 줄이기 위해 무행동 경고를 억제한다.

`npm run test:unit`은 지속 시간, 자동 복귀, 순간 깜빡임, 휴대폰과 손의 관계, 독서 문맥, 신호 누락, 추론 공백, 오래된 결과, 기존 타이머 연동과 초기화 실패 정리를 검증한다. 실제 카메라·기기별 처리속도·모델 정확도는 브라우저에서 별도 확인해야 한다.

API 참고: [MediaPipe Face](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/web_js), [Pose](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js), [COCO-SSD](https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd).
