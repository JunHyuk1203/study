# 단어앱 학습시간 연동

단어앱 저장소: `superword`.

- 단어 카드·쇼츠·테스트 화면에서 자동 시작한다. 플래시카드·객관식·주관식·따라쓰기 테스트도 모두 합산한다. 편집·설정·기록·테스트 결과 화면 또는 10초 무입력 시 시간을 보존한 채 일시정지하고, 학습 화면에서 다시 입력하면 재개한다. 백그라운드·페이지 종료·로그아웃에서는 저장 후 종료한다. 상단 캡슐은 오늘 누적시간을 표시하므로 새 세션에서도 초기화되지 않는다.
- 설정 왼쪽 기록 버튼에서 오늘·이번 주·날짜별 시간을 본다. 한국 날짜 기준이며 최근 학습 500회를 집계한다.
- 단어앱 자체 기록은 단어앱 계정의 `users/{uid}/learningSessions/{id}`에 저장한다. 로컬 대기열을 먼저 기록하고 오프라인 저장은 다음 연결 시 재시도한다. 기기 기록과 서버 기록은 ID로 병합한다.
- 스터디 연동은 별도 이름의 Firebase 앱에서 기존 스터디 이메일 또는 Google 계정으로 로그인한다. 단어앱 로그인과 독립적이다. 연동 전 기록은 소급 적립하지 않는다.
- 스터디 로그인은 Firebase의 `browserLocalPersistence`로 보관한다. 앱 재실행 시 저장소 초기화와 기존 로그인 복원을 기다린 다음 연동 상태와 타이머를 초기화한다. 비밀번호를 앱 코드에서 별도로 저장하지 않는다. 동일 브라우저·주소에서는 연동 해제나 사이트 데이터 삭제 전까지 연결을 유지한다.
- 연결 관계는 스터디 Firestore의 서버 전용 `wordAccountLinks/{wordAuthUid}`에 저장한다. 저장 시 양쪽 계정의 인증을 확인하며 ID와 갱신 시각만 보관한다. 스터디 로그인 저장소가 없어도 단어앱 로그인 토큰을 검증한 서버가 저장된 연결로 스터디 로그인용 단기 커스텀 토큰을 발급한다. 연동 해제는 서버 연결도 삭제한다. 비밀번호·ID 토큰·커스텀 토큰을 연결 문서에 저장하지 않는다.
- 스터디는 `startWordStudy` / `syncWordStudy` / `finishStudySession`을 사용한다. 영단어 과목을 재사용하거나 추가하며, 서버가 관측한 10초 유효 구간만 적립한다. 5초마다 갱신한다.
- 실제 단어 학습 시작 시 `startWordStudy`에 `tracking:true`를 보내면 서버가 같은 트랜잭션에서 카메라 적립을 멈춘 후 단어 적립을 시작하고 응답한다. 기기 타이머도 이 응답을 확인한 뒤 시작한다. 시작 응답이 늦으면 10초 무입력 기준은 시작 확인 뒤부터 적용한다. 재개는 `syncWordStudy` 한 번으로 처리하며 `ensureProfile`·`prepareWordStudy`를 반복 호출하지 않는다. 기존 클라이언트의 `prepareWordStudy` 방식은 호환성을 위해 유지한다.
- 단어 학습 중에는 얼굴인식 학습시간을 일시정지한다. 단어장 나가기·무입력·앱 종료로 단어 적립이 멈추면, 스터디 화면이 보이고 얼굴이 인식되는 상태에서 원래 카메라 세션을 자동 재개한다. 수동 일시정지는 유지한다. 강제 종료로 종료 요청을 보내지 못하면 마지막 10초 lease가 만료된 뒤 재개하며 5분 주기 정리를 기다리지 않는다. 서버 트랜잭션에서 단어 적립 시작 전 카메라 체크포인트를 정지하여 중복 적립을 막는다.
- SP word는 `visibilitychange`와 창 `focus`/`blur`를 함께 확인한다. 다른 탭·창으로 전환하면 즉시 측정과 서버 presence를 종료한다. 얼굴인식과 단어 시간은 서버에서 상호 배제하며 한 구간을 두 번 적립하지 않는다.
- 모든 세션은 5초마다 생존을 확인한다. 카메라·단어는 적립 lease 10초와 세션 생존 유예 45초를 분리하고 일반 학습은 10초 무응답에 만료된다. 접속 중인 스터디 화면은 `expireStudySessions`로 자동 종료하며, 시작 API는 만료 세션과 유실 연결을 정리한다. 갱신 API는 트랜잭션에서 현재 세션 만료를 검사한다. `closeExpiredWordStudies`는 1분마다 항목 오류를 격리하고 페이지별로 남은 기록을 정리하며, 트랜잭션에서 갱신 여부를 재확인한다. 상세 기준은 [학습 동기화 계약](study-sync-contract.md)을 따른다.
- 서버 만료·다른 창의 종료·카메라 오류로 스터디 세션이 예기치 않게 종료되면 카메라와 집중 화면을 닫고 학습 탭에서 메인으로 이동한다. 사용자가 직접 종료하는 정상 흐름은 별도로 처리한다.
- 단어앱 자체 기록은 개인 기록이며 스터디 서버는 이 값을 보상·랭킹 적립의 근거로 사용하지 않는다.
- 연동 중 캡슐과 기록 화면은 스터디 서버의 영단어 과목 기록을 사용한다. 기기 자체 기록은 별도 버튼으로 확인하며, 연동 전·오프라인 기록을 소급하여 스터디에 적립하지 않는다. 스터디도 동일한 서버 체크포인트에서 진행 중인 시간을 표시한다.
- 서버는 5초 체크포인트마다 일·주·월 집계를 새로 발생한 초만큼 갱신한다. 종료 시 이미 집계한 시간은 다시 더하지 않는다. 완료 통계·보상·랭킹은 종료 시 한 번 확정한다.

## 적용 및 배포

두 프로젝트의 변경을 함께 배포해야 서비스에서 동작한다.

1. 스터디 Functions: `prepareWordStudy`, `saveWordStudyLink`, `restoreWordStudyLink`, `removeWordStudyLink`, `startWordStudy`, `syncWordStudy`, `closeExpiredWordStudies`, 변경한 `finishStudySession`. 복원 함수의 실행 계정에는 자기 자신의 커스텀 로그인 토큰을 서명할 권한이 필요하다.
2. 스터디 웹: `study.html`, `data.js`.
3. 단어앱 Firestore rules와 웹 파일: `index.html`, `study-integration.js`, `study-timer-core.js`, `study-integration.css`.
4. 단어앱이 제공되는 호스트가 스터디 Auth 승인 도메인에 있어야 한다. 현재 설정에 `junhyuk1203.github.io`와 localhost가 포함되어 있다. Android WebView에서는 이메일 연결을 사용할 수 있다.

웹에서는 자동으로 종료 요청을 보내지만 운영체제가 프로세스를 강제 종료하면 요청 자체가 실행되지 않을 수 있다. 스터디는 서버 lease 만료와 주기 정리로 종료하며 마지막 갱신 이후 최대 10초까지만 적립한다. 단어앱 자체 기록은 마지막으로 기기에 저장한 시점까지 복구한다.

## 검증

스터디: `npm run test:unit`, `npm run test:firebase`.

단어앱: `node --test tests/study-timer.test.mjs`, `npm run test:rules`. Playwright를 NODE_PATH에 지정한 환경에서 `node tests/study-integration-ui.cjs`로 모바일/데스크톱 화면과 자동 시작·종료·기록 집계를 검증한다.
