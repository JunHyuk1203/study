# 휴대폰 인식 알고리즘 재설계 계획

작성일: 2026-10-25

상태: 2026-10-25 관측 계약·후보 추적·탐색·시간 판정 구현. 실영상 정확도 목표는 미검증이며, 모델 교체·학습 및 서버 배포는 포함하지 않는다.

## 1. 목표와 적용 범위

얼굴 가까이 가져오지 않은 휴대폰도 카메라에 충분히 보이면 탐지한다. 특히 가슴·책상 높이, 화면 가장자리, 양손이 떨어진 상태, 손에 일부 가려진 상태를 대상으로 한다. 책·계산기·리모컨 때문에 학습이 잘못 정지되는 현상도 함께 평가한다.

현재 제품의 동작인 ‘휴대폰이 반복 검출되면 학습 정지’를 기본 정책으로 유지한다. 휴대폰 존재와 실제 사용 여부는 별도 개념이다. 손과의 접촉이나 시선은 보조 증거로 사용할 수 있지만, 얼굴·손 미검출만으로 휴대폰 후보를 버리지 않는다. 책상 위에 놓인 휴대폰을 허용할지는 별도의 제품 정책이며 이번 정확도 개선과 섞지 않는다.

## 2. 코드에서 확인한 문제와 아직 확인하지 못한 원인

| 항목 | 확인한 현재 동작 | 설계에 반영할 내용 |
| --- | --- | --- |
| 탐지 모델 | 모든 확대 영역에 동일한 COCO-SSD를 사용 | 확대만으로 해결되는 경우와 모델 자체의 미검출을 분리 측정 |
| 탐색 범위 | 양손을 찾으면 손 주변 두 영역만 검사. 그 외에는 중앙 영역과 순환 사분면 검사 | 손 검출 여부와 관계없이 전체 화면 재탐색 기회 보장 |
| 시간 판정 | 신규 음성 관측 한 번이면 연속 양성 횟수가 0이 되고, `phoneUse=false`이면 지속 시간도 초기화 | 같은 물체의 독립 관측을 누적하고 짧은 누락은 제한적으로 허용 |
| 처리 지연 | 전체 화면과 최대 두 확대 영역을 순차 추론한 뒤 묶어서 결과 전달 | 결과별 촬영 시각·완료 시각을 보존하고 사용 가능한 결과부터 전달 |
| 결과 유효기간 | 촬영 시각 기준 1.5초 초과 결과를 버림 | 느린 기기에서 실제 지연과 폐기율 측정. 처리량을 줄여 신선한 관측 확보 |
| 조기 종료 | 어느 영역에서든 점수 0.2 이상이면 이후 확대 검사 중단 | 신규 약한 후보가 나오면 해당 물체 재확인을 우선 예약 |

위 동작은 코드로 확인했다. 사용자의 실제 미검출이 모델 점수, 탐색 누락, 처리 지연, 시간 판정 중 어디서 발생하는지는 실제 영상과 단계별 측정이 필요하다. 점수 0.2는 모델 출력 기준이며 ‘실제 휴대폰일 확률 20%’를 뜻하지 않는다.

## 3. 제안하는 처리 흐름

`최신 프레임 → 탐색 영역 선택 → 휴대폰 후보 검출 → 같은 후보 연결 → 새 관측 누적 → 상태 판정`

### A. 탐색과 재확인 분리

1. 초기에는 전체 화면 탐색을 수행하고, 손 주변 또는 화면 타일을 확대 검사한다.
2. 후보가 생기면 다음 탐지 기회에 그 후보 주변을 우선 검사한다. 얼굴 근접 여부는 조건으로 삼지 않는다.
3. 후보가 잠깐 사라지면 마지막 위치 주변을 넓혀 재탐색한다. 이전 상자가 남아 있다는 사실만으로 검출 성공으로 계산하지 않는다.
4. 후보 추적 중에도 일정 비율의 탐지 기회를 전체 화면·화면 타일 탐색에 배정한다. 다른 위치로 이동한 휴대폰을 다시 찾을 수 있어야 한다.
5. 타일은 영상 픽셀 비율을 고려해 만들고 서로 겹치게 한다. 각 타일의 마지막 검사 시각을 기록해 오래 검사하지 않은 곳부터 순회한다.

고정된 ‘800ms마다 모든 영역 실행’ 대신 작업 큐에서 최신 프레임만 유지한다. 탐지 한 회가 끝날 때 다음 영역을 고른다. 오래된 대기 프레임을 누적하지 않는다.

### B. 같은 물체의 증거만 합산

각 후보에 `trackId`, 원본 좌표의 상자, 모델 점수, 촬영 시각, 완료 시각, 검사 영역, 프레임 ID를 기록한다.

- 연속 관측의 상자 겹침·중심 이동·크기 변화로 같은 물체를 연결한다.
- 같은 프레임에서 전체 화면과 확대 영역이 중복 검출한 것은 관측 한 번으로 센다.
- 서로 다른 위치의 약한 후보를 합쳐 확정하지 않는다.
- 신규 후보 생성 기준과 기존 후보 유지 기준을 분리한다. 낮은 점수는 후보 재검사 예약에는 쓸 수 있지만 단독 정지 근거로 쓰지 않는다.
- 추적 상자는 다음 탐지 위치를 정하는 용도로만 사용한다. 추적 성공을 휴대폰 분류 성공으로 취급하지 않는다.

### C. 시간 판정을 상태 기계로 변경

| 상태 | 진입·유지 조건 | 동작 |
| --- | --- | --- |
| 탐색 | 최근 유효한 후보 없음 | 전체 화면과 타일을 순환 검사 |
| 후보 | 신규 검출 발생 | 후보 영역을 우선 재검사. 학습 정지 전 단계 |
| 확정 | 같은 후보가 여러 독립 프레임에서 반복 검출 | 휴대폰 경고와 학습 정지를 함께 적용 |
| 일시 누락 | 확정 후보가 잠깐 가려지거나 검사되지 않음 | 제한된 유예 동안 재탐색. 무기한 확정 유지 금지 |
| 해제 | 해당 영역을 유효하게 검사한 결과에서 반복 미검출 | 휴대폰 경고 해제 후 기존 복귀 규칙 적용 |
| 관측 불가 | 모델 실패, 과도한 지연, 유효한 최신 영상 없음 | 정상 미검출과 구분해 기존 카메라 오류·유예 정책으로 연결 |

첫 실험값은 ‘최근 2초 안의 서로 다른 프레임 3회 중 2회 검출, 두 양성 관측 사이 최소 400ms’로 둔다. 강한 단일 검출도 다음 프레임에서 확인한다. 짧은 누락 유예는 1초, 해제는 후보 영역을 실제로 검사한 신규 음성 관측 2회 이상으로 시작한다. 이 수치들은 검증 전 가설이며 확정 사양이 아니다.

다른 화면 타일만 검사한 결과, 실행 실패, 시간 초과는 해당 후보에 대한 음성 관측으로 세지 않는다. 다만 아무 새 증거도 얻지 못한 시간이 상한을 넘으면 ‘관측 불가’로 전환하여 오래된 감지를 계속 주장하지 않는다.

### D. 지연과 연산량 제어

- 얼굴 판정과 휴대폰 관측을 별도 메시지로 전달한다. 휴대폰 관측마다 고유 ID를 부여하고 최신 얼굴 상태와 결합한다.
- 촬영 시각을 완료 시각으로 덮어쓰지 않는다. 오래된 영상이 새 증거처럼 취급되는 것을 방지한다.
- 전체 화면 또는 확대 영역의 결과가 나오면 즉시 처리하고, 나머지 영역 완료를 기다리지 않는다.
- 추론 지연의 중앙값·95백분위, 유효기간 초과 비율, 후보별 재검사 간격을 기록한다.
- 느린 기기에서는 한 번에 처리하는 영역 수를 줄이고 후보 재검사를 우선한다. 전체 화면 재탐색의 최대 대기 시간도 제한한다.
- Worker에서 실행하더라도 얼굴 처리와 CPU를 공유할 수 있으므로 얼굴 판정 주기와 화면 반응성의 악화 여부를 함께 측정한다.

## 4. 모델 변경 여부를 결정하는 기준

먼저 저장된 평가 영상의 동일한 프레임에 현재 모델을 전체 화면·후보 확대 영역 각각 적용한다. 시간 판정을 제거한 상태에서도 휴대폰 후보가 거의 나오지 않으면, 시간 규칙 변경만으로는 해결할 수 없다.

이 경우 작은 물체·부분 가림·휴대폰 뒷면 사례를 포함한 데이터로 탐지 모델 교체 또는 추가 학습을 별도 비교한다. 특정 모델의 이름이나 성능을 사전 확정하지 않는다. 후보 모델은 같은 영상, 같은 기기, 같은 입력 조건에서 검출률·오탐·지연·메모리를 비교하여 선정한다.

모델 점수 기준을 일괄 낮추는 변경은 단독 해결책으로 사용하지 않는다. 낮춘 기준에서 늘어난 후보 중 실제 휴대폰 비율과 최종 오정지 빈도를 함께 측정한다.

## 5. 검증 계획과 통과 기준

### 평가 장면

- 얼굴 옆, 가슴 높이, 책상 높이와 화면 네 모서리.
- 휴대폰 앞면·뒷면·옆면, 세로·가로 방향, 한 손·두 손, 일부 가림.
- 가까운 위치부터 작은 크기로 보이는 위치까지 동일 동작 반복.
- 휴대폰 없이 독서·필기, 책·계산기·리모컨·검은 물체를 드는 장면.
- 휴대폰을 놓았다가 다시 드는 동작, 잠깐 가렸다가 나타나는 동작.
- 느린 추론, 손 미검출, 얼굴 미검출, 오래된 결과와 순서가 뒤바뀐 결과.

평가 영상은 명시적으로 제공되거나 로컬에서 동의하에 수집한 자료를 사용한다. 자동 업로드하지 않는다. 조정에 쓴 영상과 최종 평가 영상을 분리한다.

### 측정 항목

1. 프레임 단위 후보 검출률: 탐지 모델이 놓치는 정도.
2. 장면 단위 최종 감지율과 감지까지의 시간: 시간 판정까지 포함한 결과.
3. 휴대폰 없는 학습 시간당 잘못 정지한 횟수.
4. 휴대폰 제거 후 해제 시간과 짧은 가림으로 경고가 깜빡이는 횟수.
5. 추론 지연, 버린 관측 비율, 각 화면 영역의 재탐색 간격, 얼굴 판정 간격.

초기 목표는 평가 장면의 90% 이상에서 2초 안에 확정, 휴대폰 없는 학습에서 시간당 오정지 1회 이하, 제거 후 2초 안에 해제다. 화면 밖이나 물체 구분이 불가능한 크기는 별도로 기록한다. 목표 달성 여부는 실측 후 판단하며, 짧은 영상 몇 개로 시간당 오정지 목표를 입증하지 않는다.

단위 테스트에서는 후보 연결, 중복 관측 제거, 짧은 누락, 유예 만료, 관측 불가와 실제 음성 구분, 지연 결과 폐기, 정지·복귀 전이를 검증한다. 모의 모델 테스트 통과를 실제 인식률 향상으로 보고하지 않는다.

## 6. 구현 순서와 예상 변경 지점

1. **진단 계측:** 현재 모델의 후보 점수·상자·검사 영역·시각·폐기 사유를 수집해 실제 실패 단계를 구분한다.
2. **관측 계약:** `camera-inference.js`, `camera-worker.js`, `camera.js`에 독립적인 휴대폰 관측 전달과 중복 제거를 설계한다.
3. **후보 추적·탐색 스케줄러:** 별도 순수 로직 모듈로 분리하고, 후보 재검사와 전체 화면 순회를 공정하게 배정한다.
4. **시간 상태 기계:** `camera-focus.js`의 연속 양성 초기화 방식을 유효한 후보별 관측 창과 누락 유예로 교체한다.
5. **실영상 비교:** 현행과 새 알고리즘을 같은 영상에서 비교한다. 후보 검출 자체가 부족하면 모델 비교 단계로 진행한다.
6. **실기기 검증 후 반영:** 실제 개선과 성능 목표를 확인한 뒤에만 배포 대상으로 삼는다. 기존 알고리즘으로 되돌릴 수 있는 전환점을 유지한다.

우선순위는 ‘탐지 실패와 판정 실패 구분 → 후보 재확인과 시간 누적 개선 → 필요한 경우 모델 변경’이다. 사용자 요청에 따라 구현과 GitHub main 반영을 진행한다. 아래 구현 기록은 실영상 성능 목표 달성을 의미하지 않는다.

## 7. 구현 기록과 검증 경계

- `camera-phone.js`: 원본 영상의 정규화 좌표로 후보를 연결한다. 최근 2초의 해당 후보 관측 3회 중 2회 양성이며 양성 간격이 400ms 이상일 때 확정한다. 같은 프레임은 한 번만 집계한다.
- 신규 후보·확정 양성 기준은 기존 모델 점수 0.2를 유지한다. 0.12 이상 0.2 미만은 기존 후보 위치 유지에만 쓰며 확정 양성으로 세지 않는다. 점수는 확률이 아니다.
- 확정 후보는 1초간 누락 유예를 적용한다. 상자 면적 80% 이상을 검사한 독립 음성 관측 2회와 유예 경과가 있어야 해제한다. 무관한 타일·오류·오래된 관측은 음성으로 세지 않으며 증거가 만료되면 관측 불가로 전환한다. 학습 재개에는 기존 2초 정상 상태 확인이 별도로 필요하다.
- 전체 화면을 첫 작업 및 4회 중 1회 검사하고, 마지막 전체 화면 검사 시작 후 2초가 지나면 다음 작업에 우선 배정한다. 실행 중 추론을 선점하지는 않는다. 후보 재확인은 홀수 작업에 배정하고 나머지 탐색은 마지막 검사 시각이 오래된 타일부터 순회한다. 손이 양쪽에 보여도 타일 순회를 유지한다.
- 영상 픽셀 비율 기준 정사각형 타일을 겹치게 구성한다. 매 작업은 최신 프레임의 영역 하나만 복사하며 대기 프레임을 쌓지 않는다. 결과가 끝나면 다음 얼굴 프레임을 기다리지 않고 `phone-observation` 메시지를 전달한다.
- 메시지에는 고유 ID, 프레임 ID, 촬영·완료 시각, 검사 영역, 후보 상자·점수, 성공/오류, 카메라 epoch가 포함된다. 이전 epoch 결과는 버리며 휴대폰 완료 메시지가 얼굴 요청 상태나 얼굴 응답 watchdog을 갱신하지 않는다.
- 디버그 상태에 후보 ID·상자, 최근 관측, 마지막 영역 검사 시각, 최근 120개 지연의 p50/p95, 폐기 횟수·사유를 제공한다. 이미지 저장·외부 전송은 추가하지 않는다.
- 되돌리기: `camera.js`의 `phoneRedesign`을 `false`로 바꾸면 Worker의 기존 탐색 방식과 기존 집중 시간 판정을 함께 사용한다. 이전 방식의 회귀 테스트도 유지한다. 배포 시 모듈 캐시 버전 역시 갱신해야 한다.

단위 검증은 후보 연결, 중복 프레임, 2/3 확인, 짧은 누락, 유예 만료, 무관한 영역·실패와 음성 구분, 오래된/역순 결과, 타일 순회·좌표 비율, 경고·정지·복귀, 독립 메시지·epoch를 포함한다. 실제 휴대폰 앞뒷면·가림·책상 높이의 감지율, 오정지/시간 및 실기기 2초 목표는 사용자 제공 평가 영상과 실기기로 추가 측정해야 한다.
