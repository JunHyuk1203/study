# 스터디룸 상태와 공부시간

카메라 상태는 `syncStudyCamera` 체크포인트와 같은 Firestore 트랜잭션에서 방에 게시한다. 참가자가 따로 방 목록을 조회할 때까지 기다리지 않는다. 공부시간 적립은 확인된 10초 구간으로 제한하고, 카메라 연결 만료는 45초로 분리한다. 연결 만료를 휴식으로 표시하지 않는다. 수동 일시정지와 얼굴 인식 중단은 서버에서 확인한 실제 휴식으로 처리한다.

SP word가 열려 있어도 유휴 상태의 heartbeat가 이미 재개된 카메라 상태를 휴식으로 덮어쓰지 않는다. 본인 화면은 서버 응답으로 확정된 방 상태를 즉시 반영하며, 상대방 화면은 5초 간격으로 조회한다. 늦게 도착한 예전 응답이 더 새로운 상태를 덮어쓰지 못한다.

방별 누적은 `studyRooms/{roomId}.studyTotals`에 별도 보관한다. 상단 전체 학습시간이나 세션의 누적 시간을 복사하지 않는다. 방 입장 전 시간, 방에서 나간 시간, 휴식과 확인되지 않은 연결 공백은 제외한다. 세션을 종료하거나 같은 방을 재입장해도 유지하고 다른 방과는 분리한다. 마지막 참가자가 나가 삭제된 비공개방을 새로 만들면 다른 방이다.

한국 시간의 오늘, 월요일부터 이번 주, 매월 1일부터 이번 달을 각각 누적한다. 기간 경계를 넘는 확인 구간은 해당 기간에 속한 부분만 적립한다. 방 통계에는 퇴장한 사람의 기록도 포함하며, 초 단위 동점자는 함께 1위로 표시한다. 본인은 모든 참가자 카드에서 첫 번째이고 본인 카드에도 오늘의 방 시간을 표시한다.

이전 버전에는 방별 기간 기록이 없으므로 과거 전체 세션 시간을 방 기록으로 소급 복사하지 않는다. 새 방별 누적·순위는 이 기록 방식이 적용된 시점부터 쌓인다.

검증: `npm run test:unit`, `npm run test:firebase`. `tests/room-live.test.mjs`는 로컬 에뮬레이터에서 두 참가자, 조회 순서 역전, 일시정지·재개, 15초 heartbeat 지연, 단어앱 유휴 상태, 세션 종료, 같은 방 재입장과 방 전환을 실제 callable 트랜잭션으로 확인한다. `tests/room-time.test.mjs`는 자정·월요일·월초 경계와 동점·퇴장자 순위를 검증한다.
